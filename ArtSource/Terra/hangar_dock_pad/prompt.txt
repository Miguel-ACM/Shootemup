# A floating docking platform for a hangar inside a dark industrial tunnel

The player parks ships on these in the hub. They must read as clearly FLOATING above the tunnel floor: an anti-gravity hover platform, not something bolted to a wall. Design: an octagonal or round platform about 1.6 across (X and Y from -0.8 to 0.8), top surface at z = 0 and flat/empty in the middle (a ship sits there), with a raised bevelled rim, a ring of 8 small amber lamps (0.95,0.62,0.25) around the rim, and underneath (visible at the edge from above) four small hover-thruster pods with cyan (0.25,0.75,0.85) glowing rings pointing down. Thickness about 0.2 (z from -0.2 to 0.05).
Write ONE Blender 5.x Python script named `model.py` in the current directory. Do not run Blender yourself. Build only from bpy primitives, bmesh and applied modifiers. Coordinates: X right, Y screen up, +Z toward the camera (seen from straight above). Materials: flat Base Colors in the Tunnel district's palette (attached image): dark teal-grays between (0.05,0.07,0.08) and (0.26,0.31,0.31), a little dull brass (0.32,0.27,0.15); name each material tile_00..tile_15 (at most 16); small lamp accents are allowed as ordinary bright materials. No text, no hazard stripes. Flat shading, chunky bevelled forms, 400-2500 triangles. Join into ONE mesh object named `Model`, apply transforms. Export `model.obj` (+ .mtl) with `bpy.ops.wm.obj_export` (export materials, forward_axis='Y', up_axis='Z'). Render `top.png` (512x512, Cycles CPU 32 samples, orthographic straight down, world (0.06,0.08,0.09), sun from the upper left) and `angle.png` (3/4 view). Find the script directory from `__file__`, falling back to the path after `--` in sys.argv. Reply with one short paragraph describing the design.
